Gem Tetris Castle에 "재화·상점·일꾼" 시스템을 추가해줘.
아래 스펙대로 구현하되, 기존 기능(보드, 3D 건축, 모드, 아바타, 사운드)은 깨지지 않게 해줘.

## 0. 작업 순서
1. 먼저 프로젝트 구조를 읽고, 보드 매치·연쇄 처리, 벽돌(건축) 배치, 스테이지 부위(part) 진행, 모드(싱글/대전/랭크), 아바타, 저장(localStorage) 코드가 어디 있는지 파악해서 짧게 보고해줘.
2. 밸런스 숫자는 전부 하나의 설정 파일(예: economy.config.js)에 모아서 나중에 쉽게 고칠 수 있게 해줘. 코드 안에 숫자를 하드코딩하지 마.
3. 구현이 끝나면 아래 "확인 체크리스트"를 하나씩 직접 확인하고 결과를 알려줘.

## 1. 재화 구조
| 재화 | 성격 | 얻는 법 | 쓰는 곳 |
| Gem(잼) | 그 판에서만 유효. 판 시작 시 0으로 초기화 | 부위 완성, 3연쇄 이상 | 석공 상점(위기 탈출 아이템, 일꾼 고용) |
| 아다마스 | 영구 보유 무료 재화 | 플레이 보상 | 아다마스 상점(아바타 장비·옷), 싱글 전용 영구 강화, 일꾼 해금 |
| 별빛 결정 | 유료 재화 | 현금 결제 | 전설 장비 등. 실제 결제는 구현하지 말고 "준비 중" 잠금 표시만 |
- 기존 코드에 "보석 조각" 같은 무료 재화가 있으면 아다마스로 통합해줘.
- 화면 상단에 아다마스 보유량, 플레이 중에는 보드 옆에 Gem 보유량을 표시.

## 2. Gem 얻는 법 (판 안)
| 조건 | 획득 |
| 2번째 부위 완성 | +1 Gem |
| 3번째 부위 완성 | +2 Gem |
| 한 번의 연쇄가 3연쇄 이상 도달 | +1 Gem (연쇄 한 묶음당 1회) |
- 판이 끝나면(클리어든 실패든) 남은 Gem 1개당 아다마스 10으로 환급.

## 3. 부위 완성 보상 (판 안)
부위 이름은 스테이지마다 다르므로 "몇 번째 부위"를 기준으로 처리:
| 1번째 부위 완성 | 보드 맨 아래 줄의 원석·흑요석 제거 (없으면 효과 없음) |
| 2번째 부위 완성 | +1 Gem |
| 3번째 부위 완성 | +2 Gem |
| 4번째 부위 완성 | 다음 블록 한 칸에 특수 보석 다이아몬드(3×3 폭파)를 넣어줌 |
| 마지막 부위 완성 | 스테이지 클리어 |
- 부위가 5개보다 적은 건물은 마지막 부위를 클리어로 두고, 그 앞 부위들에 위 보상을 순서대로 적용.
- 보상이 나올 때 배너로 알려줘.

## 4. 석공 상점 (Gem으로 구매, 판 안)
보드 옆 "석공 상점" 버튼 또는 숫자키 1~6으로 연다. 게임을 멈추지 않고, 열려 있는 동안 낙하 속도만 30%로 늦춘다.

### 위기 탈출용 (1회용)
| 아이템 | 효과 | 가격 |
| 정(끌) | 보드의 보석 1개를 탭/클릭해 깨기. 깬 보석도 벽돌이 됨 | 1 Gem |
| 블록 바꾸기 | 지금 내려오는 블록을 다른 블록으로 교체 | 1 Gem |
| 가로줄 정화 | 원하는 가로줄 하나를 골라 제거 | 2 Gem |
- 정과 가로줄 정화는 대상 선택 모드로 들어가며, 선택 중에는 낙하가 30% 속도. ESC/취소 시 Gem 소모 없음.
- 아이템 사용 후 정상적으로 중력·매치·연쇄 판정이 이어지게.

### 궁전 가속용 (일꾼 고용, 판이 끝날 때까지 유지)
| 일꾼 | 하는 일 | Lv1 (고용 3 Gem) | Lv2 (+4 Gem) | Lv3 (+6 Gem) |
| 보석을 캐는 일꾼 | 가장 높은 열의 맨 위 칸을 대신 깨줌. 보석이면 벽돌이 되고, 원석이면 그냥 제거 | 12초마다 1칸 | 8초마다 1칸 | 5초마다 2칸 |
| 보석을 나르는 일꾼 | 내가 깬 보석이 확률적으로 벽돌 2개가 됨 | 20% | 35% | 50% |
| 보석으로 건축을 쌓는 일꾼 | 보석을 깨지 않아도 스스로 벽돌을 쌓음 (색은 이번 스테이지 보석 중 무작위) | 6초마다 1개 | 4초마다 1개 | 2초마다 1개 |
- 캐는 일꾼은 매치·연쇄 처리 중에는 대기했다가 끝난 뒤 작동.
- 일시정지 중에는 모든 일꾼 타이머 정지.
- 고용한 일꾼은 3D 하늘섬에 작은 캐릭터로 표시 (지금은 간단한 도형 플레이스홀더 OK): 캐는 일꾼은 곡괭이질, 나르는 일꾼은 궁전까지 왕복, 쌓는 일꾼은 벽돌 옆에서 망치질. 레벨이 오르면 색이나 크기가 달라지게.

## 5. 넓어지는 성장 (영구, 아다마스)
강해지는 성장 대신 선택지가 넓어지는 성장으로 만든다.

### 일꾼 해금 (싱글 모드에만 적용)
| 캐는 일꾼 | 처음부터 |
| 나르는 일꾼 | 싱글 3스테이지 클리어 또는 1,000 아다마스 |
| 쌓는 일꾼 | 싱글 6스테이지 클리어 또는 2,000 아다마스 |
- 해금 전 일꾼은 석공 상점에 잠금 아이콘으로 표시.

### 싱글 전용 영구 강화
| 강화 | Lv1 | Lv2 | Lv3 |
| 시작 Gem +1 / +2 / +3 | 600 | 1,200 | 2,400 아다마스 |
| Gem 획득량 +10% / +20% / +30% (소수점은 누적 후 정수만 지급) | 800 | 1,600 | 3,200 아다마스 |

### 대전·랭크 공정성 규칙
- 대전/랭크 모드에서는 영구 강화를 전부 무시하고, 일꾼 3종을 모두 해금된 상태로 동일하게 시작한다.
- 아다마스 장비는 꾸미기 전용이라 어떤 모드에서도 능력치에 영향 없음.

## 6. 아다마스 얻는 법
| 스테이지 클리어 | 50 + (스테이지 번호 × 10), 최대 150 |
| 별 1개마다 | 30 |
| 랭크전 승리 / 패배 | 40 / 15 |
| 랭크전 패배 광고 시청 | 20 (광고가 아직 없으면 보상 지급 함수만 만들어 둘 것) |
| 일일 미션 | 100 (미션 시스템이 없으면 "하루 3판 플레이" 미션 하나로 간단히 구현) |
| 판 종료 시 남은 Gem | 1 Gem당 10 |
- 결과 화면에 이번 판에서 얻은 아다마스를 항목별로 보여줘.

## 7. 아다마스 상점 (영구 장비, 꾸미기 전용)
메인 메뉴에 "아다마스 상점"과 "장비" 화면을 추가. 슬롯 6개(옷, 마법 지팡이, 석공 망치, 세공 장갑, 작은 망원경, 망토)에 하나씩 장착.
각 장비는 게임 속 한 장면의 연출만 바꾼다. 아트가 없으면 색·파티클·이펙트 차이로 플레이스홀더 구현.

| 슬롯 | 바뀌는 연출 | 일반 (300) | 희귀 (800) | 영웅 (2,000) | 전설 (별빛 결정, 잠금) |
| 옷 | 보드 옆·결과 화면 아바타 모습 | 견습 석공 작업복 | 광맥 탐사복 | 궁정 세공사 예복 | 황금 돔 건축왕 예복 |
| 마법 지팡이 | 특수 보석(오팔·문스톤·다이아몬드) 발동 효과 | 참나무 지팡이(흰 빛) | 자수정 지팡이(보랏빛 소용돌이) | 별지기 지팡이(유성) | 오팔 왕홀(무지개 폭발) |
| 석공 망치 | 연쇄 때 아바타 타격 모션·타격음 | 강철 망치 | 청동 단조 망치(불꽃) | 흑요석 망치(검은 불꽃) | 다이아몬드 대망치(충격파+화면 흔들림) |
| 세공 장갑 | 보석이 깨질 때 파편·반짝임 | 가죽 장갑 | 은사 장갑(은빛 가루) | 진주 실크 장갑(무지갯빛 가루) | 아다마스 건틀릿(결정 파편 궤적) |
| 작은 망원경 | 다음 블록 창 테두리, 부위 완성 때 궁전 비추기 | 놋쇠 망원경 | 항해사 망원경(나침반 테두리) | 천문대 망원경(별자리 테두리) | 황룡 망원경(용이 궁전을 휘감음) |
| 망토 | 승리 포즈·막판 러시 때 휘날림 | 석공 길드 망토 | 비단 여행 망토 | 황룡사 단청 망토 | 오로라 망토 |
- 상점에서 장착 전 미리보기 가능하게.
- 전설 등급은 "별빛 결정 · 준비 중"으로 잠금 표시만.

## 8. 저장
- 아다마스, 보유 장비, 장착 상태, 일꾼 해금, 영구 강화 레벨, 일일 미션 진행을 localStorage에 저장.
- 저장 데이터에 version 필드를 넣고, 읽기·쓰기는 try/catch로 감싸서 실패해도 게임이 멈추지 않게.
- Gem과 일꾼 고용 상태는 저장하지 않음 (판마다 초기화).

## 9. 확인 체크리스트
- [ ] 판 시작 시 Gem 0, 판 종료 시 남은 Gem이 아다마스로 환급됨
- [ ] 2·3번째 부위 완성, 3연쇄 이상에서 Gem이 정확히 지급됨
- [ ] 4번째 부위 완성 후 다음 블록에 다이아몬드가 들어옴. 마지막 부위 완성 시 클리어
- [ ] 정·가로줄 정화 대상 선택 중 취소하면 Gem이 소모되지 않음
- [ ] 일꾼 3종 레벨별 주기·확률이 설정 파일 값과 일치하고, 일시정지 중 멈춤
- [ ] 대전/랭크에서 영구 강화가 적용되지 않고 일꾼이 모두 해금 상태
- [ ] 아다마스 상점 구매·장착·미리보기 동작, 전설은 잠금
- [ ] 새로고침 후 아다마스·장비·해금·강화 상태 유지
- [ ] 기존 스테이지 1~10, 모드 고르기, 사운드, 아바타 능력이 그대로 동작
